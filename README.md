# BoilerPro SA

Starter Android application for the BoilerPro SA boilermaking trade and fabrication platform.

## Current features

- BoilerPro SA home screen
- Bend-Line Calculator
- 360° ÷ number of bend lines calculation
- Examples for 12 and 24 bend lines
- Trade-Test Training placeholder
- Jetpack Compose UI
- Navigation Compose

## Open in Android Studio

1. Extract the ZIP.
2. Open the `BoilerProSA` folder in Android Studio.
3. Allow Gradle to sync.
4. Select an Android emulator or connect an Android phone with USB debugging enabled.
5. Press Run.

## Calculation principle

For equally divided bend lines around a 360° development:

bend-line angle = 360° ÷ number of bend lines

Examples:
12 lines = 30° per division
24 lines = 15° per division
